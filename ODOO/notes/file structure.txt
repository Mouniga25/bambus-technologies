Module structure
---------------
-->creating a module, it definitely has its own structure
-->A module comprises different components such as models, views, security, etc.
--> Mainly used to manifest in Odoo module
-->All modules must have a python file and a manifest file 
that are __init__.py file and __manifest__.py file.


__init__.py:
--->we can use __init__.py to store the python packages


__manifest__.py:
we can  describe the name of the module, author name, version, description, 
company, category, etc.

models:
-------
-->The model file contains __init__.py file, which imports all python files 
on that models directory.
--> model is database struture(table and feilds) and bussiness logic(loop . function)


views:
------
-->Views file contains the XML files for the user interface.
-->the actions and views like forms, lists,search, kanban etc..
-->The format of the xml file is “sample.xml “
